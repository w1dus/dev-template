    01관리자 페이지 접속

    02관리자 메인 화면 살펴보기

    • 방문자 접속통계 — 금주 방문자 수를 확인. [바로가기]를 누르면 오늘·총·어제 방문자 수를 확인할 수 있습니다.
    • 방문자 집계 그래프 — 최근 7일간의 방문자 수를 그래프로 확인합니다.
    • 최근 문의 목록 — 최근 문의글을 확인하는 곳입니다. [바로가기]로 더 많은 문의를 봅니다.

    SECTION 03

    03푸터 정보 변경하기

    홈페이지 하단(푸터)의 주소·전화번호·이메일 등 회사 정보를 수정합니다.

    1. [환경설정] → [기본환경] 설정을 클릭합니다.
    2. 현재 페이지에서 주소, 대표변호사, 전화번호, 이메일 수정이 가능합니다.
    🔗
    전화번호 연동 안내여기서 입력한 전화번호는 우측 플로팅 아이콘의 전화상담 버튼과 연동됩니다. 연락처가 바뀌면 이 페이지에서 수정해 주세요.

    SECTION 04

    04플로팅 메뉴 링크 수정하기

    화면에 항상 떠 있는 플로팅 버튼(카톡상담·연수후기·전화)의 링크를 변경합니다.

    1. [환경설정] → [기본환경] 설정을 클릭합니다.
    2. 카톡상담 링크, 연수후기 링크, 전화번호를 수정해 주세요.

    SECTION 05

    05교육후기 올리는 방법

    교육후기 게시판에 새 글을 작성하는 방법입니다.

    1. 관리자페이지에 접속한 뒤 교육후기 게시판을 클릭합니다.
    2. 게시판에서 글쓰기 버튼을 누른 후 글을 작성합니다.

    입력 항목 설명

    • 카테고리 — 글의 분류를 선택합니다.
    • 제목 / 내용 — 후기 제목과 내용을 입력합니다.
    • 링크 1 · 링크 2 — 함께 보여줄 링크가 있다면 등록합니다.
    • 썸네일 등록 — 리뷰 목록에 노출될 대표 이미지입니다. (필수)
    • 파일 1 — 첨부할 파일이 있다면 등록합니다.
    ⚠️
    썸네일은 필수입니다등록하지 않으면 후기 목록에서 이미지가 비어 보일 수 있으니 꼭 등록해 주세요.

    SECTION 06

    06고객후기 카테고리 관리하기

    고객후기 게시판의 분류(카테고리)를 추가하거나 변경합니다.

    1. 고객후기 게시판 목록에서 [관리자] 버튼을 클릭합니다.
    2. 분류 칸에 카테고리를 입력합니다. 분류 사이는 | (세로줄)로 구분합니다.
    3. 페이지 맨 아래 [확인] 버튼으로 저장합니다.
    ✏️
    입력 예시카테고리1|카테고리2|카테고리3
